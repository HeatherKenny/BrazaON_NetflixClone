# Projeto BrazaON - Evolução do Projeto

## Conteúdo do Pacote

| Versão | Título | Descrição Principal |
| :--- | :--- | :--- |
| **V1** | Esqueleto | Estrutura básica Spring Boot e integração REST inicial. |
| **V2** | Menu | Inclusão de interface visual (Thymeleaf) e barra de navegação. |
| **V3** | Pesquisa | Implementação de funcionalidade de busca dinâmica. |
 UX/UI | Refinamento visual completo com design Dark e responsivo. |

## Documentação
Cada versão possui seu próprio arquivo de documentação detalhada dentro da pasta `docs/`.

## Requisitos
- Java 17+
- Maven
- Chave de API do TMDb (obtenha em [themoviedb.org](https://www.themoviedb.org/))
